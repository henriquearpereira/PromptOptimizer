# PromptOptimizer

A free web tool to optimize LLM prompts, helping developers craft better inputs for large language models. Built with Python (Flask), Hugging Face Transformers, and basic HTML/CSS/JavaScript.

## Features
- Input a prompt and get optimized suggestions.
- Save and share optimized prompts.
- (Future: Analyze prompt effectiveness with LLM outputs.)

## Tech Stack
- Python (Flask/FastAPI)
- Hugging Face Transformers
- HTML/CSS/JavaScript
- Hosted on GitHub Pages/Netlify

## Getting Started
1. Clone this repo: `git clone [repo link]`
2. Install requirements: `pip install -r requirements.txt`
3. Run the app: `python app/main.py`
